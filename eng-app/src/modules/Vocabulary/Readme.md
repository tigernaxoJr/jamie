## 演算法筆記(當前版本)

### 1. 優先順序

| 條件 | 判斷依據       | 權重/細節              |
| ---- | -------------- | ---------------------- | ---- |
| P1   | 未回答過       | Total Count = 0, ×1000 |
| P2   | 最近有答錯過   | Terror 屬 RECENT       | ×100 |
| P3   | 連續答錯懲罰   | Cerror_consecutive     | ×5   |
| P4   | 最近沒有回答過 | Tlast 屬 STALE         | ×10  |
| P5   | 總答錯次數     | Cerror                 | ×1   |

### 2. 演算法邏輯

1. 計算所有單詞的優先級分數
2. 根據分數從高到低排序
3. 處理緩衝區邏輯
   - 如果單字總數少於緩衝區大小，則不強制排除，而是盡量選最久沒考過的
   - 大集合策略：排除最近考過的 N 個單字 (BUFFER_SIZE)
   - 小集合策略：優先排除最近剛考過的 (lastWordIds 中的最後一個)
4. 從最高分詞彙中隨機選取一個

## 演算法筆記(2026-03-22)

### 邏輯

1. 單字本身紀錄連續答對次數、連續答錯次數、總答對次數、總答錯次數、上次答對時間、上次答錯時間
2. 設置不重複次數的參數
3. 分出2個 pool，最近一次答對、最近一次答錯
4. 優先取得不熟的作為測驗單字，原則是距離上次出現小於不重複次數

- 從錯誤的 pool 中取得單字，優先順序為：
  1. 連續答錯次數由大到小排序
  2. 總答錯次數/總答對次數由小到大排序
  3. 以上都相同的話比較上次答錯時間愈接近者優先
- 如果錯誤的 pool 沒有單字，則從正確的 pool 中取得單字，優先順序為：
  1. 連續答對次數由小到大排序
  2. 總答錯次數/總答對次數由小到大排序
  3. 以上都相同的話比較上次答對時間愈久者優先
  - 如果所有單字距離上次出現的間隔都小於不重複次數，則以距離上次出現最遠的單字作為測驗單字

5. 回答錯誤後，該單字會被移到最近一次答錯的 pool 中，並更新答錯次數
6. 回答正確後，該單字會被移到最近一次答對的 pool 中，並更新答對次數
