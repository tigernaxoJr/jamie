## 出題演算法（`domain/WordQuizService.ts`）

### 記錄

每個英文字（小寫）一筆長期記憶（`infra/WordMetaStorage.ts`，localStorage `word-metadata`）：
連續答對 / 答錯次數、總答對 / 答錯次數、上次答對 / 答錯時間。
同一個英文字出現在多個題目（例如 right：右邊 / 正確的 / 權利）時共用同一筆記錄。

- 答對：答對次數 +1、連續答對 +1、連續答錯歸零
- 答錯：答錯次數 +1、連續答錯 +1、連續答對歸零
- 用了提示（字數 / 首字）答對：不記錄
- 偷看答案、空白跳過：不記錄（不算錯）

### 選題

1. 排除最近出過的 5 個字；剩下的先洗牌，條件相同的字（例如都還沒考過）隨機出題
2. 分成兩個 pool：最近一次答錯（含還沒考過）、最近一次答對
3. 優先從答錯的 pool 出題：
   1. 連續答錯次數多的優先
   2. 答錯率（總答錯 / 總答對）高的優先
   3. 最近答錯的優先
   - 還沒考過的字排在所有答錯的字後面，彼此之間隨機
4. 答錯的 pool 沒有字時，從答對的 pool 出題：
   1. 連續答對次數少的優先
   2. 答錯率高的優先
   3. 最久沒答對的優先
5. 所有字都剛出過（單字少於 6 個時）：選最久沒出現的字

## 答案規則（`domain/answers.ts`）

- 忽略大小寫、多餘空白、句點：`mr` = `Mr.`
- 緊貼的短字尾是變化形：`shoe(s)` 接受 shoe、shoes
- 括號內是其他寫法：`airplane (plane)` 接受 airplane、plane；`be(was, were)` 接受 be、was、were
- 字數提示只算主要答案的字母：`shoe(s)` = 4 個字母
