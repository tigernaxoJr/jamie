# 字靈探險隊：遊戲性增強計畫

依「好做程度 × 效果」排序。每一項做完就在這裡打勾，並更新 `README.md` 的遊戲規則。

## 第一階段：補上收集的動力

- [x] **1. 重複的字靈可以放生換糖果**
  - 問題：一區抓齊後，再遇到的大多是已收服的字靈，捕捉沒有新的回報。
  - 做法：收服已有的字靈時，結果畫面多一個「放生，換 N 顆糖果」按鈕，
    糖果數依稀有度（常見 2、少見 3、稀有 5、傳說 10，`domain/candy.ts` 的 `RELEASE_CANDY`）。
    不想放生就照舊留在身邊。
  - 循環：抓重複字靈 → 糖果 → 孵蛋（15 顆）→ 新字靈，讓抓齊後的地區仍然值得探索。
  - 放生的糖果走 `grantBonusCandies`，不受小遊戲每日上限限制（每隻都要答 3 題才抓得到）。
- [ ] **2. 色違字靈 ✨**
  - 遭遇時 1/50 機率是色違（SVG 套 `hue-rotate`），`OwnedCreature` 加 `shiny?: boolean`，
    圖鑑另外記錄「色違已收服」。對戰、捕捉畫面加閃光特效。
- [ ] **3. 迷路字靈（錯字複習）**
  - 在探險中答錯的單字記成「迷路單字」，地圖上出現「迷路字靈」入口；
    打它時只考這些字，拼對就從清單移除，並給糖果。

## 第二階段：對戰策略

- [ ] **4. 館主字靈的特殊行為**：蓄力一回合後重擊、血量低時補血。
- [ ] **5. 防禦選項**：答對這題下回合減傷 50%。
- [ ] **6. 連擊回饋**：連續答對時傷害數字放大、畫面震動。

## 第三階段：通關後內容

- [ ] **7. 館主重賽**：拿到徽章後可再挑戰，等級 +5，出題偏向最不熟的單字。
- [ ] **8. 傳說字靈挑戰**：集滿 10 個徽章後解鎖，全部是困難拼字。
- [ ] **9. 地區圖鑑全收集獎勵**：徽章外框變金色、送一顆字靈蛋。

## 第四階段：每天回來玩的理由

- [ ] **10. 每日探險任務**：例如「用水屬性打贏 3 場」「拼對 10 個字」，完成給糖果。
- [ ] **11. 捕捉最後一題考字靈自己的英文名字**。
