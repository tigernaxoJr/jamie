# 字靈探險隊：遊戲性增強計畫

依「好做程度 × 效果」排序。每一項做完就在這裡打勾，並更新 `README.md` 的遊戲規則。

## 第一階段：補上收集的動力

- [x] **1. 重複的字靈可以放生換糖果**
  - 問題：一區抓齊後，再遇到的大多是已收服的字靈，捕捉沒有新的回報。
  - 做法：收服已有的字靈時，結果畫面多一個「放生，換 N 顆糖果」按鈕，
    糖果數依稀有度（常見 2、少見 3、稀有 5、傳說 10，`domain/candy.ts` 的 `RELEASE_CANDY`）。
    不想放生就照舊留在身邊。
  - 循環：抓重複字靈 → 糖果 → 孵蛋（15 顆）→ 新字靈，讓抓齊後的地區仍然值得探索。
  - 放生的糖果走 `grantBonusCandies`，不受小遊戲每日上限限制（每隻都要答 3 題才抓得到）。
- [x] **2. 色違字靈 ✨**
  - 遭遇和孵蛋都有 1/50 機率是色違（`domain/shiny.ts`）：身體、肚子、配件的色相轉 150 度，
    顏色太灰就改成金色，旁邊有閃爍的星星。`OwnedCreature` 加 `shiny?: boolean`，能力值和一般的一樣。
  - 圖鑑標題顯示色違收集數、格子上有 ✨，詳細頁可以切換一般／色違外觀。色違不提供放生換糖果。
- [x] **3. 迷路字靈（錯字複習）**
  - 探險中（捕捉、對戰）答錯的單字記進存檔的 `lostWords`（最多 30 個，`domain/lost.ts`）。
    累積 3 個以上，地圖上出現「迷路字靈」入口（`/adventure/lost`）。
  - 迷路字靈是看過的字靈換上「迷路的」名字，等級和隊伍最高等級一樣；出題只考迷路單字，
    選擇題的干擾選項從已解鎖地區的單字挑。在這場對戰答對就把那個字找回來。
  - 打贏給糖果：找回的字每個 1 顆，再加 2 顆。輸了找回的字仍然算，但沒有糖果。

## 第二階段：對戰策略

- [x] **4. 館主字靈的特殊行為**（`rules.ts` 的 `enemyAction`）
  - 館主字靈每回合 25% 機率蓄力（顯示「⚡ 蓄力中」），下一回合重擊 ×1.8；
    玩家可以趁機打倒牠，或換上耐打的字靈。血量低於 35% 時補 30% 血，每隻只補一次。
  - 野生字靈維持只會普通攻擊。
- [x] **5. 防禦選項**
  - 第四個招式「防禦」：聽發音選中文，答對就擋下對手下一次攻擊的一半傷害（顯示「防禦中」），
    這回合不造成傷害、不中斷連擊。只擋對手的下一次行動，對手蓄力時防禦才划算。換字靈會取消防禦。
  - 招式改成 2×2 排列，手機上四個招式都看得到。
- [x] **6. 連擊回饋**（`rules.ts` 的 `hitImpact`）
  - 連擊數、暴擊、必殺、效果絕佳會讓傷害數字變大；夠大時戰場震動。訊息顯示「N 連擊！」。
  - 對手補血的數字用綠色。只影響畫面，不影響傷害。

## 第三階段：通關後內容

- [x] **7. 館主重賽**（`domain/rematch.ts`）
  - 拿到徽章後，地圖上的按鈕變「重賽館主」：館主字靈 +5 級，只出最不熟的 20 個字（依單字權重），
    選擇題干擾選項仍用整區單字。打贏給 🍬 5 顆。
- [x] **8. 傳說字靈挑戰**（`domain/legend.ts`、`ui/pages/LegendPage.vue`）
  - 傳說字靈不再出現在野外和字靈蛋裡。地圖上有「⭐ 傳說挑戰」卡片，顯示徽章進度；集滿 10 個後可以挑戰。
  - 對戰是困難模式（`BattlePanel` 的 `hard`）：所有招式都是看中文拼英文、沒有提示，出題用所有地區的單字。
    對手 Lv 25，會蓄力和補血。打贏收服傳說字靈（Lv 25）；已經收服過的話給 🍬 10 顆。
- [x] **9. 地區圖鑑全收集獎勵**
  - 收齊一區所有字靈：地圖上那一區的卡片變金框、顯示「👑 全收集」，可以領一次 🍬 15 顆（剛好孵一顆蛋，
    `AREA_COMPLETE_CANDY`）。領過的地區存在 `completedAreas`。
  - 原本想直接送蛋，改送等值糖果，讓玩家自己決定什麼時候孵。

## 第四階段：每天回來玩的理由

- [x] **10. 每日探險任務**
  - App 已經有 Quests 模組的每日任務（含「收服 1 隻」「餵 3 顆糖果」），改成擴充它，不另做一套：
    新增「在字靈探險打贏 2 場對戰」「在字靈探險拼對 10 個字」兩種任務，並在探險地圖上顯示每日任務卡。
  - 拼字任務由 `recordAnswer(word, correct, spelled)` 回報，打贏由 `BattlePanel` 回報。
- [x] **11. 捕捉最後一題考字靈自己的英文名字**
  - 第 3 題固定考這隻字靈的英文名字（仍可選難度），畫面提示「最後一題考○○自己的英文名字！」。
  - 53 隻字靈裡有 30 隻的名字不在題庫：這些用字靈資料組題（`domain/nameWord.ts`），不寫入單字記憶，
    避免報告出現題庫沒有的字。題庫有的字照常記錄。

## 第五階段：平衡修正與字靈的個性

- [x] **12. 題目越難，招式越強**
  - 問題：撞擊是拼字（威力 10）、屬性技是選擇題（威力 20）。就算拼字答對 90%，撞擊每回合的平均傷害
    也只有屬性技的一半（0.95 vs 1.9 倍攻擊力），最划算的打法是一直按屬性技，和「練拼字」的方向相反。
  - 做法：兩個招式的題型對調（`questions.ts` 的 `MOVE_KIND`）。撞擊改成聽發音選拼法（答錯仍有一半威力），
    屬性技改成看中文拼英文（依熟練度給提示），必殺技維持沒提示的拼字。威力不變。
- [x] **13. 捕捉的名字題不再被跳過**
  - 問題：能量滿了捕捉就提早結束，但名字題在第 3 題。先打贏對戰（+3）再選兩次困難，第 2 題就滿 9 格，
    名字題不會出——越認真玩越考不到。
  - 做法：能量滿時直接跳到名字題（提示「能量滿了！」），答完名字題才能丟網。用糖果加滿能量也一樣。
- [x] **14. 水剋土**
  - 問題：土剋雷、卻沒有屬性剋土，比光（不剋也不怕）還強，而且土是最多的屬性（12 隻）；水卻怕草和雷兩種。
    館主的 30 隻字靈裡有 11 隻（4 土、7 光）沒有屬性剋得了。
  - 做法：`elements.ts` 加上水剋土。火、草、雷、土都是剋一種怕一種，水剋兩種怕兩種，光維持中立。
- [x] **15. 字靈出場會喊自己的英文名字**
  - 遭遇出現、對戰上場（第一隻對手、館主派出下一隻、換字靈）、按下必殺技時唸出 `english`（像叫聲），
    原本只有圖鑑和收服畫面會唸。每場對戰多聽幾次單字，也讓孩子記住字靈的英文名字。
  - 必殺技是拼字題、不會自動唸題目，所以在按下時喊，不會蓋掉題目的發音；這題剛好考這隻字靈的名字就不喊，
    免得洩漏答案。進化後也只喊原本的單字（不加 Super）。
- [x] **16. 字靈特性**（`domain/traits.ts`，數值在 `rules.ts`）
  - 問題：等級把物種差異蓋掉了。Lv 20 時所有字靈攻擊 48～56、血量 208～236，稀有和常見差不到一成，
    字靈只差在外觀和屬性；野生字靈也只會普通攻擊。
  - 做法：`Species` 加 `trait`，7 種特性分給 53 隻（每種 6～8 隻），從英文名字的意思挑：
    - ❤️ 強壯（血量 +20%）：Coral、Sand、Jelly、Cake、Ball、Frog、Panda
    - 👊 大力（攻擊 +15%）：Pepper、Kick、Tiger、Dragon、Crown、Shadow、Comet、Firework
    - 🛡️ 堅硬（受到的傷害 -15%）：Pebble、Acorn、Shell、Cookie、Rock、Snow、Knight、Bell
    - 🌟 閃耀（暴擊率 +20%）：Ember、Spark、Sun、Glow、Star、Rainbow、Lantern、Wish
    - 💨 靈巧（連擊 2 次就能用必殺技）：Bubble、Kite、Key、Rain、Wind、Swim、Jump、Monkey
    - 🍵 療癒（防禦成功時回 15% 血）：Candle、Cloud、Cup、Toast、Pillow、Candy、Moon、Gift
    - 💪 頑強（每場一次，被打倒時撐住剩 1 點血）：Moss、Seed、Button、Leaf、Clock、Hero
  - 三隻初始夥伴各不相同：炭炭閃耀、啵啵靈巧、苔苔頑強。
  - 對手也有特性（強壯、大力、堅硬、頑強會發動），野生對戰不再只是比等級；閃耀、靈巧、療癒只有我方會發動。
  - 圖鑑、遭遇畫面、隊伍管理卡片、館主介紹顯示特性；頑強撐住、療癒回血時對戰訊息會說明。
- [x] **17. 字靈雷達**（`domain/radar.ts`、`ui/RadarCard.vue`）
  - 問題：稀有字靈每次遭遇只有約 4～5% 機率出現（權重 6 / 3 / 1），收齊一區要靠運氣。
  - 做法：探索頁的遭遇畫面下方有雷達卡，列出這區還沒收服的字靈：沒遇過的是剪影和「神秘字靈」，
    下面寫中文意思當提示（看「太陽」猜 Sun）。點一隻再按鎖定，花 🍬 5 顆（`RADAR_COST`）。
  - 鎖定後每次在那一區遭遇有 35% 機率直接遇到牠（`RADAR_CHANCE`），沒中照稀有度抽；
    實測稀有字靈從約 4% 變成約 40%。遇到時顯示「📡 雷達找到了！」。
  - 一次只鎖定一隻，換目標要再付糖果；收服後（含孵蛋）自動關掉。存在 `radar`。
    地圖上那一區的卡片顯示「📡 雷達正在找「太陽」」。
  - 放在遭遇畫面而不是地圖卡片：地圖頁已經很滿，而且孩子是在那一區抓字靈時才會想用。
- [x] **18. 進化學新字**（`Species.evolution`、`ui/EvolveDialog.vue`）
  - 問題：進化只是名字加「超級 / Super」和光圈，沒有學到新東西。
  - 做法（題庫外的新字、先做 3 隻初始夥伴、外觀加部件並重新算圖）：
    - 炭炭 Ember → 焰焰 Blaze（火焰）：加橘色翅膀（`wings`，accent `#f97316`）
    - 啵啵 Bubble → 浪浪 Wave（海浪）：加鰭和漩渦（`fins`、`swirl`）
    - 苔苔 Moss → 花花 Bloom（開花）：頭上開一朵花（新部件 `flower`，SVG 和 Blender 都有）
  - 進化按鈕（圖鑑、隊伍管理）對有 `evolution` 的字靈開進化對話框：先唸出、顯示新單字 →
    字母方塊拼字 → 拼對才進化，拼錯回到認識新字。新字不在題庫，不寫入單字記憶。其他字靈照舊直接進化成「超級○○」。
  - `evolvedForm()` 是進化後的樣子：插畫、立體圖（`blaze.webp` 等，`export_species.mjs` 多輸出進化後的樣子）、3D 都換。
    對戰上場、必殺技喊 `creatureEnglish`（進化後喊 Blaze）。圖鑑顯示「進化：焰焰 Blaze（火焰）🔊」，
    還沒進化的寫「進化後會學到一個新單字！」。
  - 之後可以照同樣方式幫其他字靈加 `evolution`（要重算那幾隻的立體圖）。
